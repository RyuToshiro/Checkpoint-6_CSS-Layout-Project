# Checkpoint-6_CSS Layout Project

i made a replica of the Docplanner landing page built using **HTML** and **CSS**, themed around medical institutions and locations from the anime *Monster*.

## What Was Done
* **Layout & Structure:** Recreated the Docplanner webpage layout using clean semantic HTML elements and CSS box model practices (`div` wrappers, flexbox, and grid layouts).
* **Navigation Header:** Built a responsive top navigation header with custom branding.
* **Hero Section:** Included an introductory section outlining patient and physician care ethics.
* **Interactive Cards:** Created distinct sections ("For Patients" and "For Doctors") featuring country/region dropdown selectors.
* **Global Network Grid:** Designed a brand/institution grid highlighting locations and medical organizations inspired by *Monster* (such as Eisler Memorial, Tenma Clinic, and Kinderheim 511).
* **Styling:** Styled entirely with custom CSS in a separate `styles.css` file using the Roboto font and a professional color palette.
